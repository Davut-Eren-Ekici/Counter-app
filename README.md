# Counter App 🔢

JavaScript kullanılarak geliştirilmiş basit ve modern bir sayaç uygulaması.

## 🚀 Özellikler

- ➕ Sayacı artırma
- ➖ Sayacı azaltma
- 🔄 Sayacı sıfırlama
- 💾 Sayacı `localStorage` ile kaydetme
- 🔁 Sayfa yenilendiğinde kayıtlı değeri geri yükleme
- 🎨 Sayının değerine göre renk değiştirme
  - Pozitif → Yeşil
  - Negatif → Kırmızı
  - Sıfır → Beyaz
- ✨ Hover ve tıklama animasyonları
- 📱 Responsive tasarım

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- DOM
- localStorage

## 📚 Öğrendiklerim

Bu projeyi geliştirirken JavaScript'te:

- `const` ve `let`
- Değişkenler
- Fonksiyonlar
- `if / else if / else`
- `querySelector()`
- `addEventListener()`
- `textContent`
- DOM manipülasyonu
- `localStorage`
- `setItem()`
- `getItem()`
- `removeItem()`

konularını uygulamalı olarak kullandım.

## 🎯 Projenin Amacı

JavaScript'in temel konularını ezberlemek yerine uygulama geliştirerek öğrenmek ve DOM ile kullanıcı etkileşimini anlamak.
